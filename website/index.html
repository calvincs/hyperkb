Your tools change.

Keep a knowledge base outside your conversations. Connect your MCP clients to it, carry it between machines, and read it without an AI tool at all.

Understand the storage model ↗
01

Markdown is the source.

Your knowledge lives in named text files. SQLite is an index you can rebuild.

02

Each client has its own session.

Local MCP clients share the knowledge base while keeping their focus and provenance separate.

03

Sync is a choice.

Keep recording locally through outages and upgrades. Optional S3 sync checks compatibility before sharing your pending changes.

INSTALL / TERMINAL

cd hyperkb
python3 -m venv .venv
.venv/bin/pip install -e ".[mcp]"
.venv/bin/hkb init
Install ripgrep with your system package manager, then register the absolute path to hkb-mcp in your client.
